## Gracefield Montessori School Portal - Context Index

Read the following files in order before implementing features, fixing bugs, or making architectural decisions:

1. `context/project-overview.md` — Product definition, core user flows, features, and project scope.
2. `context/architecture.md` — System architecture, technology stack, storage model, boundaries, and invariants.
3. `context/ui-context.md` — Design system, color tokens, typography, atomic components, and layout patterns.
4. `context/code-standards.md` — TypeScript rules, React context conventions, Supabase integration, and styling standards.
5. `context/ai-workflow-rules.md` — Spec-driven development workflow, scoping guidelines, and protected files.
6. `context/progress-tracker.md` — Completed work, milestones, architecture decisions, and roadmap.

---

### Maintenance Rule
- Update `context/progress-tracker.md` after each meaningful implementation change.
- If changes alter system architecture or design tokens, update the corresponding file in `context/` immediately.
